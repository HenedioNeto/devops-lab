# DevOps Lab

Projeto de estudos focado em DevOps, Infraestrutura como Código, Kubernetes, Docker, Observabilidade e Cloud.

O objetivo é construir uma plataforma moderna de deploy e operação de aplicações, simulando cenários encontrados em ambientes reais de produção.

## Tecnologias

- Java
- Spring Boot
- Docker
- Kubernetes
- Terraform
- GitHub Actions
- Prometheus
- Grafana
- Loki
- OpenTelemetry
- AWS (futuramente)
